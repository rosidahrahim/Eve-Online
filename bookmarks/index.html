Bookmark Standard: Signature + J-Space ID + Class

One format for every scanned wormhole bookmark, so the in-game list always matches what is recorded in Nexum.

The format

1 · Cosmic Signature
LAL
The first three letters of the signature ID
2 · J-Space System ID
J160305
The system the signature is in
3 · Wormhole Class
C5
Class of the system
Bookmark name
LAL J160305 C5

The problem, shown

Today In-game bookmark list
"LAL C2" (boxed in red) gives the signature and the class, but not which C2 wormhole it is.
Nexum Wormhole mapper chain
Home (Trap House) has a static D382 → C2. A wandering C2 can open at the same time, so home can have two different C2 wormholes at once.
The point: from our home system (J160305) there can be two different C2 wormholes at the same time. Both bookmarks would read "C2", and with no J-Space ID there is no sure way to tell which one matches which system in Nexum.

Same bookmark, fixed

Bookmark nameMatches a system in Nexum?
LAL C2Ambiguous: could be either C2 out of home
LAL J103351 C2Exactly one system
LAL J110538 C2Exactly one system

Illustrative only: the J-IDs come from the Nexum screenshot to show how each name resolves to one node.

Why it helps

  • Instant matching. Read the J-ID off the bookmark and find the node in Nexum.
  • Clean housekeeping. When a signature is gone, delete the bookmark(s) and the matching Nexum entry for that same system, together.
  • Works alongside expiry. Bookmarks already expire on the period set by dmacc; the J-ID just makes the manual cleanup in between accurate.

How to bookmark

  1. Scan down the signature and note the first three letters of its ID (e.g. LAL).
  2. Check the J-Space system ID in the system name (e.g. J160305) and its class (e.g. C5).
  3. Save the bookmark as Signature, J-ID, Class with single spaces: LAL J160305 C5.
Guideline, not a rule. This is a suggested standard to make housekeeping easier for everyone. Use it where you can.
